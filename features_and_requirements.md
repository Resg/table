# Фичи и требования (база)

## Must-have для V1
- Виртуализация строк (без “пустоты” при скролле)
- Sticky header
- Client sorting
- Row selection (multi + checkbox)
- Column resizing
- Память настроек по `gridId` (через RTK Query mock API)
  - columnSizing
  - columnVisibility
  - sorting
  - rowSelection (опционально)

## Далее (V2+)
- Фильтры: text + set/exclude
- Дерево: parentId (expand/collapse all, selection propagation)
- Grouping (tree-group)
- Контекстное меню
- Экспорт CSV/XLSX
- Хоткеи и улучшенная клавиатура
